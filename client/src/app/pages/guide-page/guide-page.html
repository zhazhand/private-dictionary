Про додаток

Привіт, шановний відвідувачу!

Для того, щоб скористатися додатком, потрібно увійти під своїм логіном та паролем (пункт меню Login). Логин - email, пароль - має бути не менше 6 символів.
Якщо ж ти ще не зареєстрован, то спочатку потрібно пройти реєстрацію (пункт меню Registration), а потім увійти під своїм логіном та паролем.

Ідея цього додатку - сформувати індивідуальний словник (який буде постійно змінюватися). У цей словник слід додавати слова (фрази), які з якоїсь причини не піддаються швидкому запам'ятовуванню. У міру запам'ятовування ці слова зі списку можна видаляти (не має сенсу зберігати у списку слова, які пам'ятаєш твердо).
Для зручності користування додаток розбит на декілька категорій (пунктів меню).
На основній вкладці розділ неправильні дієслова (пункт меню Irregular verbs) та індивідуальний словник (пункт меню Private vocabulary).
На вкладці додатково (пункт меню Additionally) знаходяться розділи: дієслова, що вимагають після себе герундій (пункт меню Gerund), дієслова, що вимагають після себе інфінітив (пункт меню Infinitive), роздільні фразові дієслова (пункт меню Separable phrasal verbs), дієслова стану (пункт меню Stative verbs) і часто вживані фрази (пункт меню Phrases).

    Формувати список у кожній з категорій можна двома способами:
  • додавати по одному слову;
  • завантажувати дефолтний список, а потім редагувати його;

Нижче наведено основні правила користування цім додатком.

Додавання

Додавання нового елемента списку (слова чи фрази) – кнопка Add new . Варто звернути увагу, що при додаванні або редагуванні елементів у деяких розділах поле транскрипція є обов'язковим для заповнення. В інших випадках це поле є опціональним - його можна прибрати, знявши відповідну галочку (тоді в полі транскрипція запишеться символ "-").

Також слід звернути увагу: при додаванні слова (або редагуванні існуючого) зручно скористатися помічником Convenient resource. У цьому випадку, при натисканні на посилання transcription, у новій вкладці відкриється сторінка, на якій можна скопіювати транскрипцію для відповідного слова, при натисканні на посилання pronunciation, у новій вкладці відкриється сторінка з американською та англійською вимовою відповідного слова.

Щоб повернутися до вихідного списку, можна скористатися кнопкою Return .

Редагування та видалення

Для редагування або видалення елемента списку необхідно клікнути на відповідний рядок таблиці та, після переходу на сторінку редагування, або відредагувати дані та натиснути на кнопку Save , або, щоб видалити слово, натиснути на кнопку Delete .

Сортування списку

Сортувати список можна або за алфавітом (order by alphabet) або за датою (order by date) - у цьому випадку зверху списку будуть останні додані елементи.

Пошук (фільтрація) за списком

Для фільтрації списку можна скористатися полем search, куди необхідно запровадити умова фільтрації (першу літеру чи початкову частину слова). Для очищення поля пошуку потрібно використовувати кнопку із зображенням щітки.

Видалення списку

Для видалення списку - кнопка Delete list . Є два варіанти: видалити список повністю Completely , або тільки його частину Selectively .

Вибираючи варіант видалення selectively, необхідно позначити ті слова, які потрібно видалити.
Варто звернути увагу, що видалена буде відфільтрована (за полем search) частина списку.

Завантаження дефолтного списку

Якщо список елементів порожній, можна завантажити дефолтний список (і при необхідності відредагувати його). Для цього потрібно скористатися кнопкою Download default list

About the app

Hi there, dear visitor!

To use the application, you need to log in using your login and password (menu item Login). The login is your email, and the password must be at least 6 characters long.
If you are not registered, you first need to register (menu item Registration), and then log in using your login and password.

The main idea of this application is to create a personal dictionary (which will be constantly updated). To this dictionary you should add words (phrases) that for some reason are not easy to remember. As you memorize these words, you can remove them from the list (there is no point in keeping words that you remember well in the list).
For ease of use, the application is divided into several categories (menu items).
On the main tab, there is a section for irregular verbs (menu item Irregular verbs) and a personal dictionary (menu item Private vocabulary).
On the additional tab (menu item Additionally) there are sections: verbs that require a gerund after them (menu item Gerund), verbs that require an infinitive after them (menu item Infinitive), separable phrasal verbs (menu item Separable phrasal verbs), stative verbs (menu item Stative verbs) and frequently used phrases (menu item Phrases).

    There are two ways to form a list in each category:
  • add one word at a time;
  • load the default list and then edit it;

Below are the basic rules for using this application.

Adding

Adding a new list item (word or phrase) - button Add new . It is worth noting that when adding or editing elements in some sections, the transcription field is required to be filled in. In all other cases, this field is optional - it can be removed by unchecking the corresponding item (then the transcription field will contain a "-" symbol).

Also notice: when adding a word (or editing an existing one), it is convenient to use the assistant Convenient resource. In this case, when you click on the link transcription, a page will open in a new tab, where you can copy the transcription for the corresponding word, when you click on the link pronunciation, a page with the American and English pronunciation of the corresponding word will open in a new tab.

To return to the original list, you can use the button Return .

Editing and deleting

To edit or delete a list item, you need to click on the corresponding table row and, after going to the editing page, edit the data and click the button Save , or, to delete a word, click on the button Delete .

Sorting the list

You can sort the list either alphabetically (order by alphabet) or by date (order by date) - in this case, the most recently added items will be at the top of the list.

Search (filter) by list

To filter the list, you can use the field search, where you need to enter the filtering condition (the first letter or the initial part of the word). To clear the search field, you need to use the button with the image of a brush.

Deleting a list

To delete list - click on button Delete list . There are two options: delete the list completely Completely , or only part of it Selectively .

When choosing the delete option selectively, you need to mark the words that need to be deleted.
It is worth noting that the filtered (by field search) part of the list will be deleted..

Loading default list

If the list of elements is empty, you can load a default list (and edit it if necessary). To do this, use the button Download default list
